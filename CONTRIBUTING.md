# Вклад в проект

Спасибо за интерес к проекту! Ниже — краткая инструкция для контрибьюторов.

1) Клонирование и установка

   git clone <репо-url>
   cd office-booking

2) Работа с ветками

- Создавайте ветку от `main` или `master`: `git checkout -b feature/имя-описание`.
- Используйте понятные имена веток: `feature/`, `fix/`, `docs/`.

3) Коммиты и формат

- Пишите понятные сообщения коммитов: короткий заголовок (50 символов) и, при необходимости, тело.
- Рекомендуется следовать простому соглашению: `type(scope): короткое описание` (например: `fix(api): correct time parsing`).

4) Pull Request

- Создайте PR в основную ветку, опишите цель изменений и кратко укажите тесты/проверки.
- По возможности добавьте скриншоты и шаги для воспроизведения.

5) Тестирование локально

- Перед созданием PR убедитесь, что вы запустили `npm install` и проверили, что приложение собирается и запускается локально.

6) Кодстайл

- Соблюдайте существующий стиль кода в проекте. При необходимости выполните `npm run lint`.

7) Контакты

- Если изменения большие — обсудите их в issue перед реализацией.
